Entry for the [Name the Robot Band](https://make.fun/bounty/u-motasimfuad-name-the-robot-band-1ffc6a74) bounty on make.fun — one funny robot band name plus a few words on its hit song, all in a single line.

## Entry

> The Buffering Boys — their hit single 'Loading…' has been stuck at 99% since 2019, and fans are still waiting for the drop.

## How it works

`main.py` writes the entry text (123 characters, 131 bytes, no trailing newline) to `entry.txt`, resolving the output location in this order: `ENTRY_OUT` (file or directory) → `MAKEFUN_OUTPUT_DIR` → `/output/entry.txt` → `./entry.txt`.

Run it with:

```sh
python3 main.py
```
